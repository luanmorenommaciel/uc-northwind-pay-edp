## Stage — chapters for the PPT

Use this order. One idea per slide. The room does not know the domain yet, so the business comes first. Follow along: do not dump the whole tree in one breath.

### 1. Money arrives as files, once a night

- NorthWind Pay settles card payments for merchants. Money does not arrive as an API call.
- A batch lands overnight on SFTP. Java 21 parses it, Postgres holds it, the merchant is paid.
- Five live file types (`01`–`05`). Type `01` — card settlement — is the one we live in tonight.
- Distilled from a real scar (Kurv), not a toy shop.

### 2. One file, opened

- Not JSON. Not CSV. **Fixed-width mainframe records** at byte offsets fixed by the contract.
- `spec/type-01-card-settlement/samples/valid-minimal.dat` — one `H`, two `D`, one `T`.
- Amounts are **signed overpunch**. `1234E` = `123.45`. Trailer `1734E` = `173.45`. Rows agree. Batch accepted.

### 3. The same file, one letter different

- Trailer `E` → `D`. `173.45` becomes `173.44`. One byte carries the money.
- **Keep the lie. Refuse the batch.** The refusal is a result, not a crash.

### 4. Green is not the goal

- Parse can PASS. Type-check can PASS. Money: **−0.01**.
- **No oracle, no build.** Inbound prose does not outrank `contracts/`.
